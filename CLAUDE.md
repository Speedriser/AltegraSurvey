# CLAUDE.md — conventions for this repo

This is **Altegra Forms**, an internal + public form management app. Use this
file as the durable spec for any future Claude session.

## Stack (do not deviate)

- Next.js 14 App Router, TypeScript strict mode, `src/` layout, alias `@/* ->
  src/*`
- Tailwind CSS + shadcn/ui (configured via `components.json`, components live in
  `src/components/ui/`)
- Supabase: `@supabase/ssr` for cookie-based auth + browser/server clients;
  `@supabase/supabase-js` for the service-role admin client
- React Hook Form + Zod for form state and validation
- Recharts for response charts
- Lucide-react for icons
- nanoid for public tokens (length 21)
- @dnd-kit/sortable for drag-to-reorder in the form builder
- Cloudflare Turnstile for bot protection on public forms
- Upstash Redis (`@upstash/ratelimit`, `@upstash/redis`) for rate limiting

## Supabase clients (three, do not collapse)

- `src/lib/supabase/client.ts` — browser client (`createBrowserClient`)
- `src/lib/supabase/server.ts` — server component / server action client
  (`createServerClient` reading `cookies()`)
- `src/lib/supabase/admin.ts` — service-role client. **Never** import this from
  a file with `"use client"`. Only import from `app/api/**`, server actions, or
  cron routes. The file imports `server-only` to enforce this at build time.

## Auth + middleware

- Magic-link only. Domain restricted via a Postgres trigger on `auth.users`
  insert (Phase 2). The trigger reads `ALLOWED_EMAIL_DOMAIN` either through a
  `SECURITY DEFINER` helper or hardcoded — document the choice in the migration.
- `src/middleware.ts` enforces auth on all routes except: `/login`,
  `/auth/callback`, `/p/*`, `/api/public/*`, `/privacy`, and Next.js
  internals/static. The whitelist lives in `src/lib/constants.ts`.

## Coding conventions

- Server Components by default; `"use client"` only where needed (interaction,
  state, refs, browser APIs).
- Data fetching in Server Components via the server Supabase client.
- Mutations via Server Actions where possible. Route Handlers only for the
  public submit route and cron handlers.
- All inputs validated with Zod. Build dynamic schemas from question definitions
  in `src/lib/validations.ts`.
- Toast (`sonner`) on every mutation outcome. Always `revalidatePath` on
  success.
- Components stay under ~150 lines; extract aggressively.
- One-line code comments, only when the *why* is non-obvious. No decorated
  section headers.
- Error boundaries per route group with user-friendly messages.

## Database (Phase 2 — `/supabase/migrations/0001_init.sql`)

Tables: `profiles`, `forms`, `questions`, `responses`, `answers`, `audit_log`.
RLS enabled on every table.

Key policies:
- `forms.SELECT`: owner sees all; published forms readable by any authenticated
  user.
- `responses` INSERT internal: authenticated, parent published,
  `submitted_via='internal'`, `respondent_id = auth.uid()`. One-per-user enforced
  via partial unique index when the form's setting is on.
- `responses` INSERT public: client-side anonymous inserts are denied (RLS
  requires `auth.uid() IS NOT NULL`); the public submit goes through the
  service-role API route only.
- `responses.SELECT`: owner sees all responses on their forms; respondent sees
  their own.
- `responses.DELETE`: owner OR respondent (right to erasure).
- `audit_log.SELECT`: own actions only; INSERT via service role only.

RPCs:
- `submit_internal_response(p_form_id, p_answers)` — `SECURITY INVOKER`
- `submit_public_response(p_form_id, p_answers, p_name, p_email, p_ip_hash, p_user_agent)` — `SECURITY DEFINER`

## GDPR + abuse defenses

- Never store raw IP. `ip_hash = sha256(ip + daily_salt)`. The salt is derived
  from `IP_HASH_SALT + utc_date()`.
- User agent truncated to 200 chars. Both fields are abuse-only and never shown.
- Consent checkbox required before public submit; privacy notice required when
  public sharing is enabled.
- Turnstile + honeypot field (`website`) + time-trap (signed cookie, min 3s
  before submit).
- Upstash rate limits: 5/IP/10min and 20/IP/hour per public form, 50/IP/hour
  globally.
- Spam mark increments per-`ip_hash` counter; >3 silently blocks the hash for
  24h.
- Daily retention cron at `/api/cron/cleanup` deletes responses older than the
  form's `retention_days` (skip if null).
